# Dataset

Letakkan dataset terverifikasi dengan nama `putusan-50.csv` di folder ini.
Header harus sama persis dengan `CsvPutusan.HEADER` (16 kolom).
Jangan mengisi nilai hukum dengan perkiraan. Nilai yang tidak ditemukan harus 0 atau kosong sesuai tipe.
Nama terdakwa harus berupa kode anonim T001-T050. Jangan menaruh PDF putusan atau tabel pemetaan nama-kode di repository publik.
